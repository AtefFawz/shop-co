# إعدادات الحساب وتجربة الاستخدام — V7

## الإضافات

- مركز موحد لتفضيلات الإشعارات: تنبيهات التطبيق، تنبيهات الطلبات، الصوت، والاهتزاز.
- ساعات هدوء قابلة للتخصيص. تدعم الفترات التي تعبر منتصف الليل، مثل 22:00 إلى 08:00.
- تظل الإشعارات محفوظة في صندوق الوارد وعلى الخادم حتى عند إيقاف التنبيهات المنبثقة محليًا.
- لوحة أمان تعرض حالة توثيق البريد والجلسة الحالية، مع إعادة إرسال كود توثيق البريد عند الحاجة وتسجيل الخروج من هذا المتصفح.
- لوحة خصوصية لإعادة ضبط تفضيلات القراءة وإمكانية الوصول والإشعارات المخزنة محليًا.
- مزامنة تفضيلات الإشعارات بين تبويبات المتصفح عبر `storage` event.
- ترحيل إعداد الصوت القديم `shopco_notif_sound` إلى نظام التفضيلات الجديد.

## حدود التكامل مع Backend V5

لم يتم تعديل الباك إند. النسخة المرفقة توفر مسارات قراءة الإشعارات وتعليمها كمقروءة وقراءة بيانات المستخدم وتسجيل الخروج، لكنها لا توفر:

- API لحفظ إعدادات الإشعارات في حساب المستخدم.
- API لتعداد الأجهزة أو الجلسات النشطة.
- API لإلغاء جميع الجلسات أو إلغاء جلسة جهاز آخر.
- تكامل Web Push أو إدارة اشتراكات Service Worker.

لذلك:

- إعدادات الإشعارات وساعات الهدوء محلية في المتصفح الحالي، ولا توقف إنشاء الإشعارات على الخادم.
- صندوق الإشعارات يظل يعمل ويحتفظ بالإشعارات حتى عند إخفاء التنبيهات المنبثقة.
- زر الأمان ينهي جلسة المتصفح الحالي فقط باستخدام مسار تسجيل الخروج الموجود.
- لا تعرض الواجهة بيانات أجهزة أو جلسات غير موجودة في استجابة API.
- لا يوجد تفضيل مزيف للخصوصية العامة/إخفاء التقييمات؛ تمت إزالة مفاتيح الواجهة المحلية غير المتصلة بسلوك فعلي.

## إعادة ضبط التفضيلات

زر إعادة الضبط يغيّر فقط:

- `shopco-display-preferences`
- `shopco-notification-preferences`
- مفتاح الصوت القديم `shopco_notif_sound`
- مفتاح تفضيلات الحساب القديم `shopco-profile-prefs`

لا يحذف الحساب أو الطلبات أو السلة أو قائمة الرغبات أو التقييمات أو الإشعارات المحفوظة على الخادم.
