# تقرير إصلاحات ESLint — SHOP.CO

## ما تم تعديله

- استبدال استخدامات `any` الصريحة في تدفق المنتجات والطلبات والمستخدمين والمراجعات وأخطاء API بأنواع مخصصة في `src/types/domain.ts`، مع إضافة `src/lib/errorUtils.ts` لتضييق نوع أخطاء الطلبات بدل افتراض شكل الخطأ.
- توحيد أنواع بيانات الطلبات والمستخدمين في صفحات الإدارة والحسابات، وإضافة الحقول الناقصة التي يستخدمها الـ UI.
- إصلاح قواعد `react-hooks/exhaustive-deps` في المواضع التي ظهرت في تقريرك باستخدام callbacks مستقرة واعتماديات صحيحة، وتثبيت مصفوفات المنتجات الفارغة خارج المكونات لتجنّب تغيّر الـ dependencies كل render.
- معالجة أخطاء `react-hooks/set-state-in-effect` في مزامنة التفضيلات وتهيئة الـ theme/locale والـ hydration وتنظيف overlays، باستثناءات محددة فقط في المواضع التي تمثل مزامنة مقصودة مع مصدر خارجي أو حالة التنقل.
- نقل تحديث `propsRef.current` في `SpecularButton` من render إلى effect، وإصلاح معالجة التعليق في JSX وشرط `onReviewSuccess`، وإزالة imports غير المستخدمة والتكرارات.
- إصلاح `prefer-const`، إزالة `@ts-ignore` غير الضروري، وتحسين cleanup للمراجع في التنقل، وإزالة تعريف `resetAll` غير المستخدم.

## نتائج الفحوصات المتاحة هنا

- تحليل نحوي: **205 ملفات TypeScript/TSX، دون أخطاء parsing**.
- استيرادات محلية ومسارات `@/`: **لا توجد مسارات مفقودة**.
- تحليل AST للاستيرادات: **لا توجد imports غير مستخدمة أو أسماء مستوردة مكررة**.
- `any` الصريحة في annotations: **0** في ملفات المصدر.

## ما لم يتم التحقق منه

تعذّر إكمال `npm ci` لأن تنزيل الحزم توقف بالمهلة في بيئة التنفيذ، ولا يتوفر ملف ESLint التنفيذي ضمن الاعتماديات المكتملة هنا. لذلك لم أتمكن من تشغيل `npm run lint` أو `npm run build` فعليًا، ولا أزعم أن البناء الإنتاجي قد اجتاز الاختبار.

تظل تحذيرات `@next/next/no-img-element` بحاجة إلى مراجعة مستقلة؛ تحويل الصور إلى `next/image` يتطلب التحقق من أبعادها ومصادرها البعيدة حتى لا يتسبب الإصلاح الشكلي في تغيّر سلوك عرض الصور.

## التحقق على جهازك

بعد فك الضغط داخل نسخة منفصلة من المشروع، شغّل:

```bash
npm ci
npm run lint
npm run build
```

إذا ظهر تقرير جديد، استخدمه بوصفه المصدر النهائي لقواعد ESLint الفعلية؛ الفحوصات الساكنة المذكورة أعلاه لا تحل محل ESLint أو TypeScript build.
